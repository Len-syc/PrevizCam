# 场景勘察

通过 list_workspaces 选择目标，get_context 读取真实项目和 spatialContext。以网站提供的世界坐标为准：米、右手系、Y 向上。需要完整接口说明时读取 `previzcam://reference/previs-contract`。

提取场景 ID、校准说明、范围、空间锚点、人物初始位置、语义分组和可能的墙柱。将资料整理为：可用空间依据、拍摄约束、需要进一步验证的假设。语义名称是按模型节点推断的，不等于经过人工确认。

包围盒描述范围，门洞可能位于其中，不能把整个分组当作实心障碍。当前系统没有完整导航网格或可行走区域。站立高度优先参考已校准人物和锚点，遇到关键地面高度无法确定时说明缺口。

需要观察实际画面时，使用现有草案的 render_frames；尚无草案时可以创建标明用途的勘察草案。不要改正式项目来拍参考图。空间结论区分数据直接支持的事实、从图片观察的判断和规划建议。

向后续步骤交付真实 ID 和坐标依据，不凭模型名称杜撰门宽、通行能力或已验证的相机位置。

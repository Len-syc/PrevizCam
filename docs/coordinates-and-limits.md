# 坐标、时间与限制

## 坐标约定

所有位置是**经过模型校准后的世界坐标**：

| 项目 | 约定 |
|---|---|
| 单位 | 米 |
| 手性 | 右手系 |
| 向上 | `+Y` |
| 前向 | `-Z` |
| 角度 | 度 |
| `fov` | **垂直**视场角，范围 5–140 |
| `t` | 镜头内归一化时间 0–1 |

`facing` 是人物统一朝向（度）。模型可通过 `scene.transform` 做统一缩放、绕 Y 旋转与平移——校准会体现在导出的世界坐标里，Agent 不需要自己换算。

## 等效焦距

项目用 36 × 20.25 mm、16:9 视窗换算（`preview/core.mjs`）：

```
fov = 2 * atan(20.25 / (2 * mm)) * 180 / PI
mm  = 20.25 / (2 * tan(fov * PI / 360))
```

30 mm 约等于 37.30° 垂直视场角，与示例 `camera-plan.json` 中的 `fov: 37.29907750810282` 一致。

## 时间

- `shot.duration` 单位秒，必须对齐到项目帧率下的**整数帧**（24 fps 下 5 秒 = 120 帧）。
- 镜头之间硬切，不在两个不同机位间自动移动。
- 共享同一相机的多个镜头，各自按自己的时长独立播放同一条路径。
- 相机关键点 `t` 严格递增，首点必须为 0；`static` 相机只有 `t=0` 一个关键点。
- 人物走位只插值位置。`facing` 全局固定，**不能**用位置轨迹表达肢体表演或逐时刻转身。

## 采样上限

几何检查是离散采样，不是连续保证：

- 每镜最多 301 个采样时刻（`steps` 上限 300，加首点），步数取 `max(24, 路径长度/0.1, 时长×5)`。
- 纯 `static` 相机且无走位的镜头退化为单次采样。
- 相邻采样位置之间额外做一次射线相交检查，用于发现穿越。
- 移动速度超过 3 m/s 会给出提示。

## 检查覆盖与不覆盖

| 覆盖 | 不覆盖 |
|---|---|
| 相机位置与注视点过近（< 0.05 m） | 人物之间的遮挡 |
| 相机进入命名墙体/立柱包围盒 | 肢体碰撞 |
| 相机路径穿过模型网格 | 走位碰撞 |
| 移动速度超过 3 m/s | 对白时长 |
| 人物头部接近画框边缘或出画 | 真实景深 |
| 人物被场景遮挡（头/胸射线） | 精细表演与轴线/接续 |
| 固定机位约束与剧本一致 | — |

建筑内部判定**只覆盖**名称匹配墙、柱、门板等规则的网格包围盒。这类包围盒是轴对齐的，**可能高估**实际占据范围，也可能漏掉不规则结构。

## 语义分组的含义

`objects` 里的每个语义分组是一个**范围描述**，不是实体：

```json
{ "id": "approach", "name": "门外铺地与石阶", "nodeCount": 92,
  "bounds": { "min": [-6.5, -0.2, -6.93], "max": [6.5, 0.68, 4.15] },
  "note": "分组包围盒仅描述范围，不能当作实心障碍物；门洞可能位于范围内。" }
```

门洞、开口可能落在分组包围盒内部。规划机位时不能用分组包围盒当碰撞体，必须回到网站看实际渲染帧和检查结果。分组由模型名称规则推断，**需要人工校正**。

## 网格清单分页

空间上下文默认只给计数不列网格。实测示例中 `meshes.total` 为 1074，手动导出带 200 条：

- `meshLimit` 范围 1–200，`meshOffset` 从 0 起。
- `meshSort` 可选 `size`（默认，按体积降序）或 `name`。
- `meshQuery` 按名称片段过滤，`meshGroup` 按语义分组过滤。
- `nextOffset` 为 `null` 表示已取完。

不要为了「看全」拉回上千条网格，按名称定位具体网格时才用。

## 导出与录制限制

- 分镜包最多 100 个镜头，每镜首中尾三帧。
- WebM 为 1280×720 实时录制，不含音频，最长 5 分钟。
- 录制期间页面隐藏、断连、取消或编码失败会中止，**不交付部分文件**。
- 浏览器最多保留最近 5 项导出记录；完成后应及时 `get_job` 并让文件落盘到输出目录。
- 草案最多同时保留 20 份。

## 表述纪律

因为检查是采样的，交付说明里不应把「未发现提示」写成「已验证无碰撞」。项目自带的检查报告固定包含四条限制，应原样保留：

- 每镜最多 301 个离散采样时刻，并检查相邻相机位置间的相交；不是连续无碰撞保证。
- 空间分组包围盒描述范围，不等于实心障碍；内部判定只覆盖命名规则匹配的墙、柱等结构。
- 未检查人物相互遮挡、肢体或走位碰撞、对白时长、真实景深和精细表演。
- 轴线、动作接续和叙事构图需要结合实际画面审阅。
